# Clueso 調査と Concentrate への反映

調査日 2026-10-02。公式サイト、ヘルプ、公開MCPツール一覧、更新履歴を調査。ログイン後の操作・出力品質・契約プランの実機検証はしていない。以下の「確認」は公開説明の確認であり、動作品質の保証ではない。ConcentrateはFigmaと仕様への反映段階。

## 採用する構造

製品コンテキスト → 戦略・企画 → 制作計画 → 収録・素材 → 編集可能な動画と手順書 → 言語・媒体別派生 → レビュー → 書き出し・公開 → 製品変更から影響箇所を更新。

Concentrateでは、この流れを同じ制作物IDでWeb、CLI、MCPから利用する。映像ファイルだけを保存する設計では、部分修正・多言語化・更新追従が成立しないため、シーン、台本、音声、素材、同期点、手順書、派生関係を構造化して保存する。

## 調査で分かった注意点

- 自動収録は公開MCPドキュメントでも特定プラン条件がある。MCPに接続できることと、すべての操作が利用できることは別。[S3]
- 言語数はトップページの150以上と翻訳ページの60以上などで記述が一致しない。Concentrateの対応数に転記しない。音声・翻訳・字幕それぞれの実装で検証する。[S1][S6]
- テンプレートページにアクセス申請への導線がある。すべてのアカウントで同じ提供状況とは判断しない。[S7]
- 公開情報から独立したClueso専用CLIの仕様は確認できなかった。Claude Code等のCLIクライアントからMCPを使う説明は確認できる。Concentrate専用CLIは今回の独自要件。[S10][S11]
- 更新検知の精度、収録成功率、実際のレンダリング速度、APIレート制限は未検証。Cluesoの宣伝数値を目標性能や実績として使わない。
- 既存のOkara由来のSEO/GEO、ソーシャル、分析などの要件は残す。今回の追加は制作基盤であり、マーケ戦略を動画だけに狭めない。

## ShogunAIで最初に検証する流れ

「月曜の仕事復帰」の承認済み企画を選び、デモ用画面を収録。30秒縦動画、90秒横動画、画像付き手順書、X原稿を同じ素材から作る。日本語版を確認後に英語版を作る。製品の画面変更時は、該当シーンと手順の更新案だけをレビューする。登場する機能や結果は、実装とデモで確認済みのものに限定する。
